# bang_luong — hồ sơ dự án

Ứng dụng lương/phép cho Trung tâm Anh văn Joy. Repo: https://github.com/Aliuliu001/bang_luong (public).

## Tiếp tục ở chat mới
Nhắn: **“Đọc `/home/ubuntu/bang_luong/README.md` và `/home/ubuntu/bang_luong/context.md`, rồi tiếp tục dự án bang_luong.”**

Sau đó đọc `plan.md` (đặc tả đầy đủ) và `task.md` (trạng thái công việc). Dùng `context.md` làm nguồn sự thật tổng hợp; nếu có khác biệt, ưu tiên thông tin mới nhất do anh xác nhận trong chat, rồi cập nhật cả bốn tài liệu.

## Tệp tài liệu
- `README.md` — hướng dẫn tiếp tục dự án
- `context.md` — yêu cầu/đã chốt/câu hỏi còn mở
- `plan.md` — plan triển khai đầy đủ
- `task.md` — task tracker, chỉ đánh dấu hoàn thành khi đã kiểm chứng

## Bảo mật
Repo công khai chỉ chứa code và tài liệu không nhạy cảm. Không commit dữ liệu lương/BHXH thật, workbook/PDF nguồn, JSON backup hoặc PAT.
